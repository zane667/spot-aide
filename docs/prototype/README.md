# 探店参谋 · 高保真原型

静态 HTML，视觉对齐线上产品（米黄底 `#fff8eb`、品牌黄 `#ffd100`、Noto Sans SC）。不连模型、不写数据。

打开：用浏览器打开 [`index.html`](index.html)，或在仓库根目录执行：

```
cd docs/prototype && python3 -m http.server 4173
```

然后访问 http://localhost:4173/

## 两种视图

| 视图 | 用途 | 怎么进 |
| --- | --- | --- |
| **点击演示** | 走主路径：首页 → 确认 → 分析中 → 结果 → 追问 / 商户视角 / 感谢 | 默认；顶栏「点击演示」 |
| **画板导入** | 7 个 390px 画板横排，便于截图或导入 Figma / Axure | 顶栏「画板导入」，或 `index.html?view=board` |

演示句与产品一致：点「家庭聚餐」会填入「带 4 岁小孩，预算 200，想吃粤菜，要有包间」。确认页点「按这个找店」会短暂停留在分析中，再进入结果。

## 画板清单

| 编号 | 画板 | 对应产品页 |
| --- | --- | --- |
| 01 | 首页 | `/` 大输入、场景模板、热门店、三步说明 |
| 02 | 标签确认 | `/confirm` 可改标签 + 推断说明 |

| 07 | 感谢页 | `/thanks` 记下选择 |

## 导入 Figma

html.to.design 一类插件吃的是**渲染后的网页**，不是把 HTML 当组件库解析。推荐：

1. 用本地静态服务打开 **画板导入** 视图（`?view=board`）。不要用 `file://`，字体和插件都更容易失败。
2. Figma 里运行 [html.to.design](https://www.figma.com/community/plugin/1159123024920163141/html-to-design)（或同类 HTML → Figma 插件），导入当前页。
3. 导入后把每个 `.artboard`（390 宽、米黄底、带阴影的那一块）整理成独立 Frame，按 01–07 命名。
4. 备选：浏览器对每个画板单独截图（或整页长图），拖进 Figma 当参考，再描一层可编辑组件。

导入后请检查：品牌黄是否仍是 `#FFD100`、圆角胶囊按钮、雷达是否变成矢量。插件有时会把 SVG 栅格化，需要的话用 Figma 椭圆/多边形重描雷达。

## 导入 Axure

Axure 不能把这套 HTML 还原成原生部件树。可用两种做法：

1. **图片热区（稳妥）**  
   画板视图下按屏截图 → Axure 新建 390 宽面板 → 导入图片 → 在「问问 / 按这个找店 / 我就去这家」上加热区，交互跳转到对应面板。
2. **内联框架（可点）**  
   拖入 Inline Frame，链接到 `http://localhost:4173/`（点击演示视图）。演示电脑要开着静态服务。导出 HTML 原型时把 `docs/prototype` 一并带上。

不建议把整页 HTML 粘进 Axure 的「自定义 HTML」：字体、390 画板宽度和顶栏都会乱。

## 和线上的差别

原型用固定文案演示默认句，不请求 DeepSeek，标签不能真的编辑。交互热区只覆盖主路径。线上产品见 https://spot-aide.vercel.app
